# 🏏 IPL Live Analytics Dashboard

## 📍 Overview

This project is a **real-time Power BI dashboard** analyzing Indian Premier League (IPL) data, connected live to the CricBuzz API using M code. It delivers up-to-the-minute match, player, and team insights — perfect for fans, analysts, or cricket strategists.

---

## ⚙️ Features

✅ Live data connection through Power Query M code  
✅ Dynamic match center (current scores, targets, run rates)  
✅ Inning-wise and player-wise performance breakdown  
✅ Season-long points table with auto-updated standings  
✅ Custom DAX measures for detailed insights

---

## 📊 Dashboard Sections

- **Live Match Center:**  
  🏏 Current score, innings split, run rates, batting and bowling stats

- **Player Contribution Analysis:**  
  🔥 Runs, boundaries, strike rates, dot balls, wickets

- **Points Table Overview:**  
  🏆 Matches played, wins/losses, net run rates, total points

---

## 💻 How to Use

1️⃣ Open `IPL_Project.pbix` in **Power BI Desktop**  
2️⃣ Make sure you are connected to the internet  
3️⃣ Hit **Refresh** to pull live CricBuzz API data  
4️⃣ Explore the dashboard interactively using slicers and filters
